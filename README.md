A make.fun entry for the competition **"Sum up 25 November's world news in one image"** (`news-image-20261125`).

`main.py` draws a 1024x1024 newspaper front page for Wednesday, 25 November 2026 — the Ukraine war at sea, the Strait of Hormuz tanker attacks, the Huawei verdict, Dell's AI orders, and the Gaza aid crisis — using pure Python 3 standard library only (no third-party packages, no network, no clock, no randomness). Two runs write byte-identical PNG output.
